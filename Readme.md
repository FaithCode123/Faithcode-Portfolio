### 🔥 PROJET À LA UNE - EN PRODUCTION

### **CV229.ai 🇧🇯 - Générateur de CV Pro pour le Bénin**

> **Le projet le plus complet - Déployé et utilisé**

**CV229** aide les jeunes béninois à créer un CV professionnel + lettre de motivation en 2 minutes sur mobile.

**Fonctionnalités :** Photo obligatoire, 18 champs validés, sauvegarde auto localStorage, Export PDF natif, Lettre de motivation auto-générée, Partage WhatsApp direct.

**Pourquoi c'est différent ?** Design premium ROSE #e9407a / BLEU #1b2a4e, 100% Mobile-First, pensé pour le marché local (quartiers, langues Fon, etc).

**Stack :** Next.js 15 (App Router), TypeScript, Tailwind CSS, Vercel CI/CD
**Liens :** [🚀 Live Demo](https://cv229.vercel.app) - [💻 Code Source](https://github.com/FaithCide123/cv229)
